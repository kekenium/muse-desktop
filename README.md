# Muse Desktop（非公式）

Meta の AI エージェント **Muse**（[muse.ai](https://muse.ai/)）を Windows デスクトップで使うための、個人制作の Electron ラッパーアプリです。

> **注意**：これは Meta 公式のアプリではありません。Muse 本体の提供は Meta が行っており、このアプリはその Web 画面を表示するだけの入れ物です。利用には各自の Muse アカウントが必要です。このアプリ自体に誰かのログイン情報が含まれることはありません。

## 機能（現行 v3.5）

- メイン用とサブ用の **2つのウィンドウを同時表示**（アカウントごとにログインを保持）
- 終了時に開いていたウィンドウを次回起動時に復元
- 通知はアカウント別に出て、クリックするとそのアカウントのウィンドウが開きます
- トレイ常駐、Windows 起動時の自動起動（トレイメニューで切替）

## ショートカット

| キー | 動作 |
|---|---|
| Ctrl+Alt+M | 最後に使ったウィンドウの表示／非表示 |
| Ctrl+Shift+1 | メインのウィンドウを開く |
| Ctrl+Shift+2 | サブのウィンドウを開く |
| F5 | 再読み込み |

## 使い方

1. Releases からインストーラーをダウンロードして実行します（未署名のため、初回は Windows SmartScreen の警告が出ます。「詳細情報」→「実行」で進んでください）
2. 開いた画面で、自分の Muse アカウントにログインします

## 開発

```bash
npm install
npm start        # 開発起動
npm run dist     # インストーラーを dist/ に作成
```

- ビルドには `build/icon.png` が必要です（現在はローカルで管理しており、初回ビルド時に配置します）
- `package.json` の electron / electron-builder のバージョンは初回ビルド時に実環境へ合わせて調整します
